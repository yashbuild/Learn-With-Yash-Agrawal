a session with GPT Realtime

1
→ connect — open a WebSocket to the realtime endpoint
2
→ session.update — configure modalities, instructions, and tools
3
→ input_audio_buffer.append — stream mic audio chunks continuously
4
← response.audio.delta — receive the model's voice in chunks
5
← function_call_arguments.done — model wants to call one of your tools
The full session flow. Connect, configure, stream audio. The model streams audio back and can also send tool calls. Steps 3-5 repeat in a loop.

session.update

you → model

configure what the model can do

{ "type": "session.update", "session": { "modalities": ["audio", "text"], "instructions": "You are a helpful assistant", "tools": [{ "type": "function", "name": "update_screen_html", "description": "Update the HTML on screen", "parameters": { ... } }] } }
First event after connecting. Set modalities, instructions, and register tools. The model uses this to decide when and how to call your tools.

input_audio_buffer.append

you → model

send chunks of your voice

{ "type": "input_audio_buffer.append", "audio": "dGhpcyBpcyBiYXNlNjQgZW5jb2RlZC..." } // raw mic audio → base64 encode → send // 24kHz, 16-bit PCM // sent continuously while the mic is on
Capture audio from mic, base64 encode, send as this event. You keep sending these continuously. 24kHz, 16-bit PCM. Each chunk is about 42ms of audio.

response.audio.delta

model → you

the model speaks back in chunks

{ "type": "response.audio.delta", "delta": "c29tZSBiYXNlNjQgYXVkaW8gZGF0YS..." } // base64 audio chunk → decode → play on speaker // streams in real-time as the model "speaks" // you hear it before the full response is done
Mirror of the previous event. Model sends audio as base64 chunks. You decode and play on speaker. Streams in real-time — you hear it as it generates.

function_call_arguments.done

model → you

the model wants to call one of your tools

{ "type": "response.function_call_arguments.done", "name": "update_screen_html", "arguments": "{\"html_code\": \"<div style='...'>...</div>\"}" } // the model DECIDED to call this tool // you receive the name + arguments // YOUR code executes it locally

AI decides what to call. Your code executes it.

The magic event. The model heard "draw a red circle," decided to call update_screen_html, generated the HTML, sent it to you. YOUR code renders it. That's client-side tool calling.
